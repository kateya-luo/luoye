# V1.5.2 纯电压电量显示

V1.5.2 将电量百分比彻底改为被动只读值：同一滤波电压永远得到同一百分比，不再保存或模拟一个独立的“电量进度”。

## 计算链路

1. 每5秒读取一次 MAX17048 的电池端电压。
2. 对最近最多5个电压样本做中值滤波；偶数个样本取中间两项的平均值。
3. 将滤波电压直接代入 V1.5.0 确定的 3.180–4.100V 分段曲线。
4. 将结果直接提交给界面，不再进行第二层百分比限速或确认。

插入或拔出 USB 时会清空旧电压窗口，新供电状态的第一个电压样本立即生效，避免充电电压和放电电压相互污染。

## 已删除的行为

- 删除充电时每30秒最多上涨1%。
- 删除放电时每60秒最多下降1%。
- 删除放电百分比不允许回升的限制。
- 删除未 Charge Done 时最高99%的限制。
- 删除 Charge Done 强制把百分比写成100%的行为。
- 删除重启后会与运行中限速状态不同的虚拟百分比状态。

因此，滤波电压达到4.100V即可显示100%，但 BQ25186 仍可能继续其恒压和终止阶段。Charge Done只控制“充电中/已充满”文字，绝不控制百分比或充电寄存器。

## 保持不变

- BQ25186 仍按原有1A充电、1050mA输入限流、恒压终止及自动补充策略工作。
- 3.180V显示0%，4.100V显示100%，中间非线性曲线不变。
- 充电页每跨5%执行一次FAST。
- 时间每分钟局刷、每10分钟FAST、每逢00分FULL。
- 显示0%不限制录音和上传；3.100V连续三次物理欠压只负责安全关闭正在写入的WAV。
