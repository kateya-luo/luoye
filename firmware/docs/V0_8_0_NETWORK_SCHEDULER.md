# 落叶 v0.8.0 网络调度与 API/2 发布说明

配套版本：ClearMeeting `0.14.0` / `luoye-device-api/2`。

## 本版本完成内容

- 在线录音维持 160 KiB 分片，字幕状态轮询上限为 4 秒。
- 完全离线录音与断网缺口统一使用固定 10 MiB 逻辑范围；无 2 MiB 回退。
- 10 MiB 正文使用 64 KiB 缓冲从 SD 流式发送，不在 ESP32 内存中整块展开。
- 单一网络调度任务统一处理在线录音、收尾、历史同步、待办、议程和存储命令。
- 每个通道独立退避，一次 HTTP 完成后重新仲裁；录音 SD writer 完全独立。
- 服务器 ACK、范围覆盖和上传模式写入 `upload.state`，断电/唤醒后继续。
- 远端不完整会话先取消再删除 SD；完整云端会议不会随 SD 副本删除。
- 正在录音或安全收尾时禁止休眠；闭合离线队列在联网失败 60 秒后允许持久休眠。
- 局域网 `YOUR_LAN_SSID` 使用 `http://192.0.2.10`，其他网络使用
  `http://meeting.example.invalid:34567`（仅工程版明文 HTTP）。

## 自动验证门槛

1. ESP-IDF v5.5.4 全量编译成功，目标 ESP32-S3、16 MiB Flash。
2. 状态机、存储格式、配网表单、上传协议、实时协议、议程协议主机测试全部通过。
3. API/2、无 2 MiB 回退、单调度器、手动 FIFO、删除和 UI154 静态门禁通过。
4. 配套服务器真实 HTTP 测试必须覆盖乱序范围、重复范围、双账号隔离、MARK、
   原子完成、取消和解绑令牌失效。

自动门禁通过只代表 `BUILD_PASS`。烧录真板后还需验证在线录音、纯离线录音、
中途断网补洞、重启续传、云端删除、60 秒休眠与按键唤醒，才进入 `BOARD_PASS`。
