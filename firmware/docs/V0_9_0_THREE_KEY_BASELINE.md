# 落叶 v0.9.0 三功能键交互基线

配套服务器：ClearMeeting v0.14.2；设备协议：`luoye-device-api/2`。

## 三键定义

| 状态 | 录音键 | 待办键 | 设置键 |
|---|---|---|---|
| 待机 | 单击开始录音；长按进入同步确认 | 单击进入/翻阅日程；长按开始待办、松开保存 | 单击进入设备状态；长按配网 |
| 录音 | 单击暂停/继续；长按安全结束 | 单击写入重点 MARK；长按无操作 | 单击切换字幕/状态；长按锁定 |
| 锁定 | 无操作 | 无操作 | 长按解锁 |
| 待办确认 | 无操作 | 单击确认 | 单击取消 |
| 同步确认 | 无操作 | 单击开始上传 | 单击取消 |
| 日程 | 单击开始录音；长按进入同步确认 | 单击下一页 | 单击返回主页；长按配网 |

提醒页、配网页、错误页和保存页具有更高的上下文优先级，不执行待机态全局动作。

## 日程分页

- 每页两条；每条第一行显示时间，下面最多两行显示内容。
- 页数为 `ceil(可见待办数 / 2)`，页码显示 `当前页/总页数`。
- 主页单击待办键进入第 1 页；继续单击循环到下一页，末页后回第 1 页。
- 任意日程页单击设置键立即返回主页。
- 日程 revision 更新时重置到第 1 页；没有数据时显示空状态 `1/1`。

## 输入安全规则

- 短按只在松手且未达到长按阈值时产生，因此长按不会先误触短按。
- 待办录音的 RELEASE 事件由 MARK/待办键产生，REC 不再负责待办松手收尾。
- 待办录入、待办确认、同步、配网、录音收尾等覆盖页会屏蔽不适用的按键动作。
- 录音中的 MARK、字幕/状态切换、锁定/解锁仍然保留。

## UI 来源

- 现有 21 页沿用已验证布局。
- `02_agenda` 单独取自用户确认的 `luoye_ui_layout_22pages_with_icons.json`。
- 合并后的可复现布局：`docs/luoye_ui_layout_v090.json`。
- 布局 SHA-256 记录在 `assets/ui154/manifest.json`。

## 验收重点

1. 待机短按录音键不会进入同步；长按录音键不会开始录音。
2. 长按待办键开始采音，松手后结束并进入云端解析/确认流程。
3. 待办确认页单击待办键确认、设置键取消。
4. 三条以上日程不会重复，页码和每页两条保持一致。
5. 日程页连续按待办键循环翻页，设置键一次返回主页。
6. 录音中待办键仍能写入重点 MARK，设置键仍能切页和锁定。
