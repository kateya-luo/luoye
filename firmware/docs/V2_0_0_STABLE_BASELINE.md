# V2.0.0：稳定基线

V2.0.0 由已完成真机稳定验证的 V1.7.2 原样升版。

本次只更新固件版本号、构建目录和发布标识，不改变运行逻辑或参数：

- 保留 SDSPI 永久内部 DMA 中转及读写根因修复；
- 保留 SD 20 MHz；
- 保留单任务串行上传、10 MiB 分段、SHA 和断点续传；
- 保留既有电量、充电、界面刷新、录音及日程策略；
- 继续兼容 `luoye-device-api/2`；配套服务器由 `0.21.0-upload-progress-r9` 同步重新编号为 `2.0.0`。

此前发布目录中的 `V2.0.0 live-caption` 属于早期实验分支，不是本稳定基线。
后续版本应以本目录和 `stable-sdspi` 发布包为准。
