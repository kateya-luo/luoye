# V1.5.0 被动电量显示策略

V1.5.0 只调整用户看到的电量百分比，不改变 BQ25186 的充电寄存器、1A 充电电流、1050mA 输入限流、恒压终止和自动补充充电策略。

## 电压映射

电池电压先经过 5 次采样中值滤波，再按下列锚点做分段线性插值：

| 电压 | 百分比 | 电压 | 百分比 |
|---:|---:|---:|---:|
| 3.180V | 0% | 3.650V | 30% |
| 3.200V | 1% | 3.700V | 39% |
| 3.250V | 2% | 3.750V | 48% |
| 3.300V | 3% | 3.800V | 57% |
| 3.350V | 4% | 3.850V | 66% |
| 3.400V | 5% | 3.900V | 75% |
| 3.450V | 7% | 3.950V | 83% |
| 3.500V | 10% | 4.000V | 90% |
| 3.550V | 15% | 4.050V | 96% |
| 3.600V | 22% | 4.100V | 100% |

3.180V 以下显示 0%，4.100V 以上显示 100%。曲线在低电区下降更快，符合本机完整放电数据呈现的锂聚合物放电末端特征。

## 显示稳定规则

- 电压窗口为 5 个样本，每个样本间隔约 5 秒，取中值抑制瞬时负载和充电纹波。
- 新百分比连续确认 3 次后才成为稳定目标。
- 放电时百分比不因静置回弹而上升；10% 以上最多每分钟下降 1%，10% 以下确认后直接跟随低电目标。
- 充电时最多每 30 秒上升 1%；BQ25186 尚未报告 Charge Done 时最高显示 99%。
- BQ25186 连续确认 Charge Done 后显示 100%。
- 插拔 USB 时清空旧电压窗口；拔线后立即按当前电池电压重新定基准，避免刷机或低电启动后长期卡在 0%。

## 与设备控制解耦

- 百分比仅用于屏幕和离线 `power.csv` 诊断，不决定充电是否继续。
- 显示 0% 仍允许开始录音、继续录音和上传。
- 数据安全只保留独立物理欠压保护：未接 USB 且电压连续 3 次不高于 3.100V 时，若正在录音则安全修复并关闭 WAV。该保护不属于电量百分比策略。
- MAX17048 原始 SOC 继续写入诊断日志用于对比，但不再作为屏幕百分比或充电控制输入。
