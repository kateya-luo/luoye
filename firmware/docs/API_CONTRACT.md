# 落叶固件 API 契约

适用版本：落叶 `v0.9.1`、ClearMeeting `v0.14.2`。

## 基础契约

- 协议：`luoye-device-api/2`
- 音频：PCM S16LE、16 kHz、单声道、16 bit
- 在线分片：160 KiB
- 离线/补洞逻辑范围：10 MiB，不降级为 2 MiB
- 所有已认证请求由固件网络调度器串行仲裁，录音写 SD 不依赖网络

## 配对与认证

设备通过 `/api/v2/device/pair/start` 和 `/pair/status` 配对。业务请求使用与账号、设备和 `binding_generation` 绑定的设备 token；解绑后旧 token 失效。

## 在线录音

设备创建 `upload_mode=live` 会话后，将实时音频发送到 `/audio/{seq}`。每片携带绝对字节偏移、字节数和 SHA-256。服务器同时返回连续文件游标和当前实时 epoch 游标。

录音中断网时继续写 SD。网络恢复后，固件调用 `/live-resume`，从当前录音位置建立新实时 epoch，立即恢复当前字幕；断网缺口不会阻塞当前声音。

## 手动补洞

存在断网缺口的录音停止后，固件调用 `/defer`，本地进入等待手动同步状态。用户长按中间键进入同步页，单击中间键确认后，固件调用 `upload-plan`，只按服务器返回的缺失范围上传 `/audio-range`。全部范围补齐后调用 `/complete`。

服务器按绝对时间轴把补传转写插回原会议。设备和服务器重启均保留进度，重复范围按偏移、长度和 SHA-256 幂等处理。

## SD 删除

设备管理的 SD 删除与云端会议历史完全独立：

- `delete_sessions` 只删除指定的本地录音目录；
- `delete_all_closed` 只删除本机当前绑定下的全部已闭合录音目录；
- 不调用会议取消接口，不查询上传完成状态，不按保留天数限制；
- 正在写入的录音延迟到安全闭合后执行；
- 删除结果只作为存储命令 ACK 上报，不删除云端会议、字幕、纪要、待办或音频。

旧的 `cleanup_synced`、自动保留天数策略和 SD 删除前云端 `cancel` 路径不属于 v0.8.2。

## 调度优先级

1. 在线录音音频与字幕；
2. 录音安全收尾、MARK、`defer/end/complete`；
3. 用户手动同步；
4. 语音待办；
5. 议程；
6. SD 清单和删除命令。

失败任务仅设置自身的下次重试时间，不用长时间延时占住整个网络任务。
