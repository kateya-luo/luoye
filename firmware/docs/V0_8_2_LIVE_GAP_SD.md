# 落叶 v0.8.2 实时断网恢复与独立 SD 删除

配套服务器：ClearMeeting v0.14.2；设备协议：`luoye-device-api/2`。

## 录音网络规则

- 在线时：按 160 KiB 分片上传，服务器实时转写。
- 录音中断网：麦克风和 SD 录音不停止，断网起点持久化到 `upload.state`。
- 录音中恢复网络：从当前录音位置建立新的实时 epoch，立即上传现在说的话；不在实时通道追赶旧缺口。
- 停止时仍有缺口：本地文件进入“等待手动同步”，不会自动在后台长期占用网络。
- 用户长按中间键进入同步页，单击中间键确认后，按服务器返回的缺失范围用 10 MiB 逻辑块补传。
- 服务器完整确认后，本地文件才进入已完成清理流程。

## 固定式 SD 删除规则

- 网页单项删除和一键删除全部只操作 SD 本地录音文件。
- 不调用服务器会议取消接口，不删除、不修改云端会议历史。
- 不要求录音达到指定天数，也不检查是否已经上传。
- 当前正在写入的录音不会被直接破坏，命令在安全收尾后执行。

## 验收日志

串口重点观察：

- `LY|UPLOAD|event=live_gap`
- `LY|UPLOAD|event=live_resume`
- `LY|UPLOAD|event=defer`
- `LY|SYNC|...`
- `LY|STORAGE_CMD|...`

验收时必须确认：恢复网络后的新字幕先出现；断网内容仅在手动同步后补入；删除 SD 后云端历史仍可打开。
