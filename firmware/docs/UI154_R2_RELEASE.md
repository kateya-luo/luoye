# 落叶 v0.7.0 UI154-r2 工程版

## 基线

- 面板：GDEY0154D67 / SSD1681 / 200×200 / 1-bit
- 业务基线：落叶 v0.7.0 轻量双麦录音、断网补传、议程待办与自适应充电
- UI 布局：`luoye-ui-layout/v3`
- 页面：22
- 动态文字字段：130
- 固定图标位置：20
- 布局 SHA-256：`8a48be441477e57a69809ec35fb88f2eb9c4c2212364cd2a6533bfc4687828ac`

## 本版变更

1. 22 张静态资源只保留叶片、曲线、状态图形等画面元素。
2. 固定图标按最终 JSON 的坐标和尺寸合入页面资源。
3. 所有文字由 `font16.bin` 在运行时绘制；时间、电量、日程、字幕、录音状态、配网和绑定信息可实时变化。
4. 文字坐标、字号、行高、最大行数和对齐方式由生成的 `ui154_layout_generated.c` 统一管理。
5. 录音字幕仍以 8 秒为周期使用 SSD1681 FAST 刷新；待机主页按分钟刷新。
6. 中间键长按进入同步确认页，短按中间键开始上传，BACK 取消；历史录音按最早优先顺序同步。
7. 云端完整确认后自动清除对应本地录音；网页可删除任意已结束的本地录音，不再要求先上传完成。

## r2.1 EPD 修复

`r2-final` 在连续刷新时错误地相信 SSD1681 深度睡眠后的旧帧 RAM 仍然有效，可能把未初始化的旧帧参与差分快刷，表现为整屏随机噪点。`r2.1-epdfix` 在 ESP32 内存中保存上一帧，并在每次唤醒后同时重载旧帧 RAM2 和当前帧 RAM1；BUSY 超时也会终止快刷基线。请使用 `r2.1-epdfix`，不要继续使用 `r2-final`。
