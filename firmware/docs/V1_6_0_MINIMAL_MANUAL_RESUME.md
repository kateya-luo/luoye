# V1.6.0 R2 最小化手动断点续传

本版从稳定的V1.5.2重新建立，不包含V1.6.0 R1的NVS自动恢复设计。

唯一行为变化：

- 设置键离开同步进度页时，只返回主页，不取消后台上传。
- 再次进入同步页并按待办键确认时，立即重新武装上传调度，取消旧的重试等待时间。
- 上传任务重新选择SD卡中的原会话；对于 `bulk`/`repair` 会话，下一步仍然调用服务器 `upload-plan`。
- 服务器返回的 `missing_ranges` 是续传位置的唯一依据。
- 同步确认页不再根据可能滞后的本地 `backlog_s` 宣称“当前没有待传录音”，而是始终允许检查服务器并继续。

保持不变：

- 10 MiB范围与SHA校验。
- 单上传任务。
- TCP、HTTP缓冲、Wi-Fi省电切换和SD 20 MHz参数。
- 每个完整范围收到服务器确认后写入SD卡 `upload.state`。
- `/complete` 成功且 `missing_ranges=[]` 后才完成并清理本地录音。
- V1.5.2电量显示与V1.5.1墨水屏刷新策略。

本版不承诺无人操作的断电自动上传。设备复位后，用户重新进入同步页并确认一次，即可继续服务器尚未收到的范围。
