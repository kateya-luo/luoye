# 落叶 v0.8.1 待办与多 Wi-Fi 工程版

配套服务器：ClearMeeting v0.14.1；设备协议保持 `luoye-device-api/2`。

## 本版变化

- 主页将下一条待办拆为时间一行、内容最多两行；无时间待办显示“未定时间”。
- 议程协议增加 `has_time`，无时间待办不再被丢弃，也不会触发 RTC 提醒。
- 最多保存 8 个历史 Wi-Fi；启动、唤醒和掉线重连时扫描当前环境，在已保存网络中
  选择信号最强者。连接失败时下一轮会尝试其他可见的已保存网络。
- 兼容旧版单 SSID NVS 数据；第一次升级无需重新配网。

## 真板验收

1. 确认主页时间独占一行，长事项能换为两行且不越过屏幕底边。
2. 分别确认有时间和无时间待办都能保存、同步、显示。
3. 配置两个热点后重启，关闭最近配置热点，确认自动连接另一已保存热点。
4. 串口检查 `LY|WIFI_SELECT|saved=... matched=... selected=...`，日志不应包含密码。
