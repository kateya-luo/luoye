# 落叶 v0.7.0 电源、RTC、长稳与固定 SD 管理

版本：`0.7.0`
服务端：ClearMeeting `0.13.0`
协议：`luoye-device-api/1`（新增 `storage_management` 能力）

## 固件行为

- 电量低于或等于 5% 后锁定新录音和新语音待办；充电或恢复到 8% 才解除，避免阈值抖动。
- 录音中电量到 3% 时复用可靠录音收尾路径，先完成 WAV 头、日志与同步，再退出录音。
- MAX17048 读失败时按电池电压保守估算电量；正常样本使用三点中值滤波，临界低电量不延迟。
- PCF8563 的 VL、校时差值、闹钟设置和真实唤醒来源写入结构化串口日志。
- GPIO41 不是 RTC IO：存在日程提醒时使用 light sleep 等待 PCF8563 INT；无提醒时使用按键深睡唤醒。
- 每 10 分钟输出 uploader 堆、最大连续内存、PSRAM、栈余量和补传积压诊断。

## 固定式 SD 管理

- 设备分页上报总容量、可用容量、本地会话、上传状态与是否允许删除。
- 网页删除命令可以在设备离线时排队；上线后设备执行并回执。
- 删除前设备重新读取持久 manifest。仅当会话已关闭、PCM 全部分片确认、MARK 确认、final 确认且绑定代次一致时才允许删除。
- 默认自动策略：低于 15% 可用空间时，删除 30 天前的已上传副本，直到达到 20%；服务器可修改或关闭策略。
- 删除只影响录音笔本地副本，不删除云端会议、字幕、纪要或待办。

## 自动化门禁

- ESP-IDF v5.5.4 编译与分区容量检查。
- 状态机、掉电 WAV 修复、配网表单、上传协议、字幕协议、议程协议主机测试。
- 服务端账号隔离、存储清单、不可删除会话拒绝、命令投递与回执测试。
- Web Client 单元测试与生产构建。

72 小时运行、200 次录音收尾、断网补传、异常断电、RTC 多次唤醒和 SD 满载属于真板验收，由用户执行，不计入自动化构建通过。
