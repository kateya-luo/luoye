# ClearMeeting v0.15.0 服务器升级说明

本版本把“议程、提醒、待办”整理为统一事项页面。落叶固件继续使用 v0.8.2，
无需重新烧录；设备既有的事项标题、时间、完成状态和 revision 同步协议保持不变。

## 主要变化

- 新增统一事项时间线：置顶、逾期、今天、未来、未安排。
- 每项可设置截止时间、负责人、优先级、提醒、备注。
- 支持编辑、完成、恢复、置顶、单项删除、批量删除和清空已完成。
- 自然语言输入先解析为“时间 + 内容”，进入确认抽屉后再保存。
- 自动迁移旧 `agenda_todos` 数据，不删除旧议程和设备语音待办。
- 继续兼容 `luoye-device-api/2` 与落叶固件 v0.8.2。

升级采用完整服务器包覆盖方式，但必须保留现有 `server/data/` 和
`deploy/.env`。升级后 `/api/v2/build-info` 的 `server_version` 应为
`0.15.0`，登录页应显示 `Web Client V0.15.0`。
