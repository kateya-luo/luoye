- 这些 STEP 早于 2026-08-30 的主板/麦克风板 EPRO，没有与最新 ECAD 重新做联合干涉检查。
- 当前仓库没有与最新板框严格对应的 PCB 装配 STEP。

打印定版或开模前，应重新核对屏幕窗口、USB/SD 开口、麦克风声孔、按钮行程、螺柱、电池空间、板间连接和装配公差。
